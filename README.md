## 🚀 Featured Projects

### Duseat
*Real estate discovery and agent communication mobile platform for Egypt & the UAE.*

**Stack:** Flutter · Dart · REST APIs · State Management

- End-to-end multi-platform property listings, interactive maps, and localized Arabic/English UI
- Real-time agent messaging, instant push notifications, and lead management flow
- Clean feature-first architecture with predictable state management

---

### Kalmangy
*Interactive trivia and word puzzle mobile game.*

**Stack:** Flutter · Dart · Custom Game Engine Logic · Local Caching

- 180+ curated challenges across 12 unique trivia & word categories
- Dynamic UI/UX with smooth transitions, custom game loops, and sound effects
- Offline-first architecture and responsive layouts across all mobile screen sizes

---

### Off-Plan Finder
*Automated crawler and analytics tool for off-plan property investments.*

**Stack:** Node.js · Web Scraping · MongoDB · Automation

- Real-time pipeline aggregating daily updates across new real estate developments
- Data filtering, price change tracking, and automated alert feeds
